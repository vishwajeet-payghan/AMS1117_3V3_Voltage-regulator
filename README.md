# AMS1117_3V3_Voltage-regulator
Compact AMS1117-3.3 voltage regulator PCB designed to convert 4V–12V DC input into a regulated 3.3V output. Features input/output filter capacitors and 2-pin connectors for easy interfacing with microcontrollers and embedded systems. PCB dimensions: 13.04 mm × 31.95 mm.
