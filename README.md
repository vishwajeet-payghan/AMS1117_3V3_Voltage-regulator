# AMS1117-3.3V Voltage Regulator PCB

A compact PCB designed using the **AMS1117-3.3V voltage regulator** to convert an input DC voltage into a stable, regulated **3.3V DC output**. The board supports an input voltage range of **4V to 12V DC** and includes input and output filter capacitors for improved voltage stability.

### Features

- **Voltage Regulator:** AMS1117-3.3V
- **Input Voltage:** 4V–12V DC
- **Output Voltage:** Fixed 3.3V DC
- **Input Capacitors:** 0.1µF and 10µF
- **Output Capacitors:** 0.1µF and 10µF
- **PCB Dimensions:** 13.04 mm × 31.95 mm
- **Input/Output:** 2-pin connectors for easy interfacing

### Applications

- Power supply for ESP32 and other microcontrollers
- Arduino and embedded electronics projects
- 3.3V sensors and peripheral modules
- Prototyping and electronics development

### Note

As the AMS1117-3.3V is a linear regulator, the voltage difference between input and output is dissipated as heat. Ensure adequate thermal management and do not exceed the regulator's current and thermal limits.

**Designed for compact, simple, and reliable 3.3V power regulation.**
